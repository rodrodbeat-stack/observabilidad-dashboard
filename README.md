# SKYNET // Observability Operations Center

Dashboard futurista de observabilidad con radar animado, telemetría, flota de servidores, eventos y trazas distribuidas.

## Publicación
El sitio está preparado para GitHub Pages y se publica mediante `.github/workflows/deploy.yml`.

## Importante
La interfaz actual funciona en modo demostración: métricas, servidores, eventos y trazas son simulados. Para monitorear infraestructura real hay que integrar una fuente de datos (por ejemplo Prometheus/Node Exporter) y configurar los endpoints correspondientes.
